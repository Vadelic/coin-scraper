# MCP Tools — coin-catalog-mcp

Сервер экспортирует **8 tools** с именами, совпадающими с Python [`tools/tools.json`](../../tools/tools.json).

Каждый tool возвращает **одну text-часть** — JSON по [`docs/coins_catalog.schema.json`](../../docs/coins_catalog.schema.json).

## Общий контракт ответа

| Поле | Описание |
|------|----------|
| `scraped_at` | ISO 8601, время начала сбора |
| `scrape_status` | `ok` \| `captcha_blocked` \| `error` |
| `total_pages` | Обработано страниц каталога |
| `total_coins` | `len(coins)` |
| `coins[]` | `catalog_number`, `name`, `metal`, `weight_g`, `buy_price`, `sell_price` |
| `query` | Только если передан непустой поиск |
| `investment_only` | `true` — только если включён фильтр |
| `error` | Обязателен при `scrape_status` ≠ `ok` |

**По умолчанию** (как в skills): передавать `investment_only=true` для инвестиционных монет, если пользователь не просит весь каталог.

## coin-catalog-zoloto-md

**Сайт:** https://spb.zoloto-md.ru  
**Описание:** Каталог монет Золотой монетный двор. JSON: список монет, цены, статус сбора. Поиск через `query`; при `investment_only` — фильтр `country=Россия`.

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `query` | string | нет | Поиск в каталоге: название, металл, каталожный номер |
| `investment_only` | boolean | нет | Только монеты эмитента Россия |
