# Aurumex Coin Catalog

## Когда использовать

- Нужен каталог монет Aurumex (aurumex.ru), только **в наличии**.
- Нужно **найти монету** в этом банке (по названию, артикулу, металлу, весу, цене и т.п.).
- Нужна сводка или аналитика по каталогу Aurumex.

Данные только из tool `coin-catalog-aurumex`, не из памяти модели.

## Порядок действий

1. Вызвать `coin-catalog-aurumex`.
   - Узкий поиск — параметр `query` (пост-фильтр по `name` / `catalog_number`; на сайте поиска нет).
2. Распарсить единственный JSON из stdout (stderr — логи, не парсить).
3. Если `scrape_status` ≠ `ok` — сообщить статус и текст `error`, не выдавать цены как актуальные.
4. Дальше — поиск монеты и/или сводка (см. ниже).

Каталог собирается **только** со страницы `/catalog` (без карточек `/products/`). В запросах tool — `availability=true`.

## Поиск монеты

1. Сформировать `query` из запроса: название («Георгий Победоносец»), металл («золото»), артикул (`10`, `319`) и т.д.
2. Вызвать tool с `query`, если поиск узкий; для обзора — без `query`, затем отфильтровать локально.
3. В `coins[]` оставить записи по смыслу: `name`, `catalog_number`, `metal`, `weight_g`, `buy_price`, `sell_price`.
4. Пользователю: для каждой подходящей монеты — `name`, `catalog_number`, `metal`, `weight_g`, `buy_price`, `sell_price` (₽; `null` → «нет данных»).
5. Если совпадений нет — «не найдено» + что искали; при необходимости другой `query` или уточнение у пользователя.

`sell_price` и `buy_price` в JSON — **за 1 монету** (опт «Кол-во 1» → цена после названия → для упаковок «N шт» пересчёт по «Цена за унцию»).

## Сводка и аналитика

При запросе на обзор каталога:

- банк: Aurumex, `scrape_status`, `total_coins`, при наличии — `query`;
- min/max `buy_price`, min/max и медиана `sell_price` по валидным значениям;
- топ по `metal`;
- доля пропусков в `name`, `buy_price`, `sell_price`, `metal`.

## Правила устойчивости

- Не читать JSON-файлы на диске — только stdout tool.
- Числа цен брать из JSON; при обработке строк — убрать ₽ и пробелы.
- Отсутствующее поле — «нет данных».
- Пустой `coins` или ошибка сбора — ответ без падения, с объяснением.

## Важные пути
