# Россельхозбанк Coin Catalog

## Когда использовать

- Нужен каталог монет Россельхозбанка (coins.rshb.ru).
- Нужно **найти монету** в этом банке (по названию, артикулу, металлу, весу, цене и т.п.).
- Нужна сводка или аналитика по каталогу РСХБ.

Данные только из tool `coin-catalog-rshb`, не из памяти модели.

## Порядок действий

1. Вызвать `coin-catalog-rshb`.
   - Полный каталог — без параметров.
   - Поиск на сайте — параметр `query` (`?search_text=` в URL): ключевые слова из запроса пользователя.
   - **Цена продажи** (`sell_price`) — с карточек каталога (элемент `.price-box`); зависит от региона. По умолчанию tool выставляет cookie `x-region=77` (Москва). Другой регион — параметр `region` (`--region "…"`), код как при выборе региона на coins.rshb.ru.
   - **Цена выкупа** (`buy_price`) — параметр `with_buy_price` (`--with-buy-price`): после витрины открывает страницу каждой монеты; медленно, лучше сузить через `query`.
2. Распарсить единственный JSON из stdout (stderr — логи, не парсить).
3. Если `scrape_status` ≠ `ok` — сообщить статус и текст `error`, не выдавать цены как актуальные.
4. Дальше — поиск монеты и/или сводка (см. ниже).

## Поиск монеты

1. Сформировать `query` из запроса: название («Георгий Победоносец», «победон»), металл («золото»), артикул (`5215-0036`) и т.д.
2. Вызвать tool с `query`, если поиск узкий; для обзора по всему каталогу — без `query`, затем отфильтровать локально.
3. В `coins[]` оставить записи, подходящие по смыслу: `name`, `catalog_number`, `metal`, `weight_g`, `buy_price`, `sell_price`.
4. Пользователю: для каждой подходящей монеты — `name`, `catalog_number`, `metal`, `weight_g`, `buy_price`, `sell_price` (₽).
   - `sell_price: null` — нет цены на витрине (нет в наличии в выбранном регионе или позиция без цены).
   - `buy_price: null` — выкуп не запрашивали (`with_buy_price` не передавали) или на странице монеты нет блока выкупа.
5. Если совпадений нет — «не найдено» + что искали; при необходимости другой `query` или уточнение у пользователя.

## Сводка и аналитика

При запросе на обзор каталога (не только одна монета):

- банк: Россельхозбанк, `scrape_status`, `total_coins`, при наличии — `query`;
- указать, что `sell_price` — для региона по умолчанию (Москва, `x-region=77`), если пользователь не просил другой регион;
- min/max `buy_price`, min/max и медиана `sell_price` по валидным значениям;
- топ по `metal`;
- доля пропусков в `name`, `buy_price`, `sell_price`, `metal`.

## Правила устойчивости

- Не читать JSON-файлы на диске — только stdout tool.
- Числа цен брать из JSON; при обработке строк — убрать ₽ и пробелы (на витрине цена часто без символа валюты, например `107 000`).
- Отсутствующее поле — «нет данных».
- Пустой `coins` или ошибка сбора — ответ без падения, с объяснением.
- Не путать: `sell_price` всегда с витрины (один проход); `buy_price` только при `with_buy_price`.
