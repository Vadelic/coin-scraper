# Золотой монетный двор Coin Catalog

## Когда использовать

- Нужен каталог монет Золотой монетный двор (spb.zoloto-md.ru).
- Нужно **найти монету** (по названию, артикулу, металлу, весу, цене и т.п.).
- Нужна сводка или аналитика по каталогу этого банка.

Данные только из tool `coin-catalog-zoloto-md`, не из памяти модели.

## Порядок действий

1. Вызвать `coin-catalog-zoloto-md`.
   - **По умолчанию всегда** передавать `investment_only` (`--investment-only`, на витрине `country=Россия`) — монеты эмитента Россия.
   - **Исключение:** пользователь явно просит **весь** каталог, все страны-эмитенты или «все монеты» — тогда `investment_only` **не** передавать.
   - Узкий поиск — параметр `query` (`--query "…"`): строка поиска уходит в URL витрины (`query=…`), сочетается с `investment_only`.
   - Для обзора без поиска — без `query`.
2. Распарсить единственный JSON из stdout (stderr — логи, не парсить).
3. Если `scrape_status` ≠ `ok` — сообщить статус и текст `error`, не выдавать цены как актуальные.
4. Дальше — поиск монеты и/или сводка (см. ниже).

## Поиск монеты

1. Сформировать `query` из запроса: название («Георгий Победоносец»), металл («золото»), артикул и т.д.
2. Вызвать tool с `investment_only`, если не запрошен полный каталог; с `query`, если поиск узкий.
3. В `coins[]` оставить записи по смыслу: `name`, `catalog_number`, `metal`, `weight_g`, `buy_price`, `sell_price`.
4. Пользователю: для каждой подходящей монеты — `name`, `catalog_number`, `metal`, `weight_g`, `buy_price`, `sell_price` (₽; `null` → «нет данных»).
5. Если совпадений нет — «не найдено» + что искали; при необходимости другой `query`.

## Сводка и аналитика

При запросе на обзор каталога (не только одна монета):

- банк: Золотой монетный двор, `scrape_status`, `total_pages`, `total_coins`, при наличии — `query`, `investment_only`;
- min/max `buy_price`, min/max и медиана `sell_price` по валидным значениям (`buy_price` — с карточки каталога; `null`, если на карточке «Звоните» или нет числовой цены выкупа);
- топ по `metal`;
- доля пропусков в `name`, `buy_price`, `sell_price`, `metal`.

## Правила устойчивости

- Не читать JSON-файлы на диске — только stdout tool.
- Числа цен брать из JSON; `sell_price` — только стандартная цена с витрины (не клубная); `buy_price` — цена выкупа с карточки (не клубная).
- Отсутствующее поле — «нет данных».
- Пустой `coins` или ошибка сбора — ответ без падения, с объяснением.
- Не вызывать tool без `investment_only`, если пользователь не просил явно весь каталог — иначе в ответ попадут монеты всех стран-эмитентов.
